    Read this before applying

    • Argue with the exclusions. These are pattern calls on posting text, not readings of a hiring manager's mind. Each filtered role shows its reason. If one looks wrong, it probably is, and it is still on the page.
    • Years shown in bold came from the posting. Only 225 of 491 do. Where the number is greyed, the employer published nothing and the band comes from the job title instead, which means a Senior AE title lands in the Senior band on a convention rather than a fact. Use the Years published filter when you want only the ones you can trust.
    • Postings expire. Some of these will already be closed. That is normal for a list this size and not a reason to distrust the rest.
    • Confirmed open means a page showing the live requisition was actually loaded. Roles without that badge surfaced in search results but the page could not be opened, usually because LinkedIn or an applicant tracking system blocks automated access.
    • Aggregator links go stale first. Where a row links to Indeed, ZipRecruiter or Glassdoor, the employer's own careers page is the better route. Every row carries a backup search link.
    • Blank pay is not low pay. Ranges shown are only the ones the employer published.
